## - Projeto de estudo somente.

Decidi iniciar esse projeto para estudar a integração de Arduino(hardware) com software no sistema operacional via browser e servidor intermediário(Java). 
Estou implementando a UI inteiramente em HTML, CSS e JS que se comunica via API Java. Por fim esse último se comunica via comunicação serial com o Arduino. 
Projeto perfeito para estudar integração de software + hardware e padrões de projeto, já que não estou usando nenhum framework.

Fiz a UI em um estilo Retro, aliás, porque não...
